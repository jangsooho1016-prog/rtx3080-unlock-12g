# MSI RTX 3080 SUPRIM X 12G LHR 포트

원본은 MSI RTX 3080 **10GB** 한 장(`10de:2206`, subsystem `1462:3890`, VBIOS `94.02.59.00.aa`)과 한 대의 PC에 모든 검사를 고정해 두었습니다. 이 포트는 대상을 **RTX 3080 12GB(`10de:220a`)**로 바꾸고, 카드·PC마다 달라지는 값은 추측하지 않고 **내 PC에서 읽기 전용 프로브로 측정한 값**으로 채우도록 바꿨습니다.

> 12G 카드에서 실제로 실행해 본 적은 없습니다. 빌드와 검사 로직만 확인했습니다.

## 바뀐 점

| 항목 | 원본 (10GB) | 이 포트 |
| --- | --- | --- |
| PCI ID | `0x220610de` 고정 | `0x220a10de` (`unlock/board_ids.h`) |
| Subsystem | `0x38901462` 고정 | 프로브 측정값 |
| 사용 가능 VRAM 레지스터(`0x1183a4`) | `0x2800` (10240 MiB) | 프로브 측정값 (12G는 `0x3000` 예상) |
| BAR0 주소 | `0x84000000` 고정 | 프로브 측정값 (메인보드가 배정) |
| Cold SS0 / PLM | `0x46254040` / `0xffffff8f` | 프로브 측정값 |
| PROM(VBIOS) SHA256 | 10GB 카드 해시 | 내 카드의 `PROM.BIN` 해시 |
| 설정 공간 `0xc8`, class/rev, BOOT0 | 고정 | 프로브 측정값 |

측정값은 `unlock/board_measured.h`에 들어가며, 이 파일이 없거나 다른 GPU에서 만든 것이면 **빌드가 실패**합니다. 단위 테스트는 원본 10GB 증거를 재생하므로 `unlock/tests/board_fixture_3080_10g.h`로 따로 돌아갑니다.

## 사용 순서

1. **프로브 빌드** (읽기 전용, GPU 쓰기·리셋 없음)
   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\build-probe.ps1
   ```
2. FAT32 USB에 `probe\build\BOOTX64.EFI` → `USB:\EFI\BOOT\BOOTX64.EFI`, 빈 폴더 `USB:\RTX3080-PROBE`를 만듭니다.
3. 모니터를 **메인보드(Intel 내장그래픽)** 에 연결하고 Secure Boot를 끈 뒤, PC를 **완전히 끈 상태에서** 켜서 USB로 부팅합니다.
4. `USB:\RTX3080-PROBE\RUN00\`에 생긴 `REPORT.TXT`, `PROM.BIN`으로 프로필을 만듭니다.
   ```powershell
   python .\tools\make_board_profile.py --report E:\RTX3080-PROBE\RUN00\REPORT.TXT --prom E:\RTX3080-PROBE\RUN00\PROM.BIN --output .\unlock\board_measured.h
   ```
   `ERROR`가 나오면 그 카드/PC 상태로는 진행하지 않습니다. `WARNING`은 원본과 다른 값이라는 뜻이고, 특히 **SS0 값이 다르면** 원본에서 검증된 경로가 아니라는 뜻입니다.
5. 이후는 원본 README·`docs/USB-BOOT.md`와 같습니다 (`unlock\build.ps1` → `tools\package_usb.py`).

## 이 포트로도 안 되는 조건

- **Intel 내장그래픽 화면 출력이 필수**입니다. F 모델 Intel CPU나 내장그래픽 없는 Ryzen이면 화면 검사에서 거부됩니다.
- GPU가 `0000:01:00.0`(첫 번째 x16 슬롯)에 있어야 합니다.
- 실행 자산 5개(`unlock/assets.json`)와 Windows 드라이버 버전은 원본과 같은 610.x 계열을 전제로 합니다.

## 위험

- 코드상 VBIOS 플래시에 쓰지 않고, 효과는 전원을 완전히 끄면 사라지는 것으로 설계되어 있습니다. 그래도 GPU 보안 펌웨어(FWSEC/Booter)를 직접 구동하고 기능 선택 레지스터를 바꾸는 실험이므로, 실패 시 멈춤·드라이버 오류가 날 수 있습니다. `STOP / POWER OFF`가 나오면 전원 버튼으로 끄세요.
- 12G 카드는 VBIOS·퓨즈 버전이 10GB와 다를 수 있어 Booter 서명 선택이나 SS0 해제가 그대로 통하지 않을 수 있습니다.
